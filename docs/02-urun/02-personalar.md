# Personalar

## İkincil personalar

- **Franchise sahibi (bayi)** — kendi şubesinin kayıtlarını görür (Gözlemci rolü, salt okunur). Rolün genişliği pilot bulgusuna bağlı (açık karar).
- **Gıda müfettişi / marka denetçisi** — ürünü kullanmaz; PDF çıktısını ve doğrulama kodunu görür.
- **Destek uzmanı (Talimatname)** — müşteri hesaplarında "bildirim gelmiyor / fotoğraf yüklenmiyor" sorunlarını teslimat izi ve cihaz günlüğüyle çözer.
