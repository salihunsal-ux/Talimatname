# Görüşme notları

Pilot keşif görüşmelerinin notları buraya, görüşme başına bir dosya: `YYYY-MM-DD-zincir-adi.md`. Şablon: görüşme rehberi §09 (not formu) — alanlar rubrikle birebir. Uyum puanı ve Kapı 1 sayımı `00-ozet.md` tablosunda tutulur.

Kişisel veri: görüşülen kişinin adı ve iletişim bilgisi bu depoya yazılmaz; yalnızca unvan ve zincir adı.
