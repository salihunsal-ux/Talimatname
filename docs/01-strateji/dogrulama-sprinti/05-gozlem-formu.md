# Şube ziyareti gözlem formu

Kapanış vardiyası, 30 dakika. Dosya adı: `gorusmeler/YYYY-MM-DD-zincir-kodu-gozlem.md`. Fotoğraf yalnızca izinle ve personel yüzü olmadan; personel adı yazılmaz. Amaç: merkezin anlattığıyla sahadakini karşılaştırmak; fark bulgudur.

```
---
tur: gozlem
tarih: 2026-09-
zincir_kodu: ""
sube: ""              # semt/şube adı
sube_saatleri: ""
ziyaret_saati: ""
gorusme_ref: ""       # ilgili merkez görüşme notunun dosya adı
---
```

## 1. Fiziksel ortam

| Gözlem | Cevap |
|---|---|
| Tablet var mı? Nerede (kasa/bar/ofis), kilitli mi, personel dokunuyor mu, marka/OS | |
| Wi-Fi adı ve personel erişimi; mutfakta sinyal (telefonla test, 1–4 çubuk) | |
| Duvarda/kapı arkasında liste veya form var mı? Son doldurulma tarihi; aynı kalem/aynı anda mı doldurulmuş? (fotoğraf) | |
| Sıcaklık defteri var mı? Kaç ekipman? Ölçüm aleti (prob/termometre/dolap göstergesi) | |
| QR/etiket asılabilecek istasyonlar ve sayısı (buzdolabı, fritöz, tuvalet, depo…) | |
| Ortam: nem, yağ, eldiven — dokunmatik kullanımı etkiler mi? | |
