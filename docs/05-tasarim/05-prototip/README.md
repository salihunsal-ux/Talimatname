# Blok 8 prototipi

`blok8-prototip.html` — görüşme rehberi Blok 8'de gösterilen tıklanabilir prototip (tek dosya, bağımlılık yok, telefonda tam ekran). Akış: kiosk PIN → Bugün → kapanış listesi (onay, sıcaklık aralık dışı → fotoğraf + not + kritik aksiyon, yapılamadı) → gönderim → bölge müdürünün sabah özeti → çalıştırma detayı ve olay izi. Sağdaki görüşmeci panelinden ekranlara atlanır; isim testi için marka seçici (Talimatname, yap lütfen, tamamlist, tembihle) — sırayı her görüşmede değiştirin.

Veri kaydetmez; kamera sahtedir; sıcaklık ± ile girilir. Canlı sürüm (telefon için): bkz. 00-urun-merkezi.md dış bağlantılar.
